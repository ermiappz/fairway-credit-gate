# Fairway Credit Gate

**Public prototype · fictional demo data · prepared 28 October 2026**

Six fictional member scenarios and four refused attacks executed through the compiled circuit simulator. Inspect private profile fields beside the resulting public loan record.

[Open the private hosted demo](https://fairway-credit-gate-ermiappz.ermiarch.chatgpt.site) · [Original reference implementation](REFERENCE-README.md) · [Validation and scope](DEMO-VALIDATION.md)

## Run locally

Use Node 22 for the credit gate; Python 3 can serve the static presentation.

```sh
npm ci
npm run typecheck
npm test
npx tsx demo/export.ts
make demo
```

The hosted view is also included as a standalone static site:

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory presentation
```

Open `http://127.0.0.1:8080`. The production URL requires the owning ChatGPT account. GitHub repository access is separate.

## Data and scope

The replay is generated by `demo/export.ts`, with signatures obtained from controlled provider records keyed by the member hash. Its member-level tiers are synthetic and distinct from institutional DEMO-0.1. No ZK proof is generated and no network transaction is submitted by this lane. The separate proof-based setup is documented in `REFERENCE-README.md` and was not exercised for this deployment.

The browser view shows fictional scenarios and recorded local execution. It does not approve real loans or submit transactions.

## Publication and access

This repository is public for technical review. Its member records and Finnish walkthrough scenarios are fictional. Obsidian documents, Linear exports, local credentials, captured register responses, and original wallet keypairs are not included. The hosted demo remains owner-private; reviewers can serve `presentation/` locally using the command above.

The original reference documentation is preserved in `REFERENCE-README.md`, `DEMO.md`, and `WALKTHROUGH.md`. The Finnish browser walkthrough is a simulation, not a verified TLSNotary attestation or a confirmed Midnight transaction.
