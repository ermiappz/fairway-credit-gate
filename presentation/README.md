# Browser demonstration

Serve this directory over HTTP. `data.json` is the snapshot/replay payload; `app.js` and `styles.css` implement the interactive views. Source strings are escaped before rendering. No external scripts, fonts, analytics or live backend calls are used. This Credit Gate repository is public; cross-project links point to separate private Sites.

The top-level workspace `demo-console/build.py` assembles these files from repository-owned demo outputs. Each committed presentation directory is independently runnable. This Credit Gate snapshot contains fictional records and is published for review. Other project Sites remain private.
